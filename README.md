# Mixer de Áudio — downloads (Windows 11 x64)

Este repositório hospeda **apenas os instaladores** (ZIP) do Mixer de Áudio —
o voice changer para Windows 11. O código-fonte é mantido em repositório privado.

## Como instalar

1. Baixe o `instalador-mixer-de-audio.zip` da versão mais recente em
   [**Releases**](../../releases/latest).
2. Extraia TODO o ZIP para uma pasta e dê dois cliques em `INSTALAR.bat`.
3. Algo não funcionou? Dois cliques em `CORRIGIR.bat` (verifica e corrige sozinho).

**Requisito:** Windows 11 de 64 bits.

## Atualizações

A partir da versão **1.0.7**, o app verifica este repositório na abertura e
**se atualiza sozinho** quando há versão nova (desligável com `AutoUpdate: false`
no `settings.json`). Versões anteriores: basta rodar o `INSTALAR.bat` do ZIP novo.

A integridade (SHA-256) de cada ZIP está nas notas da respectiva release.
